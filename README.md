# Labra website

Static Ukrainian and English website for the Android app. Preserve the existing GitHub Pages base path /labra-site/.

Run a static HTTP server in this directory, then open /uk/ or /en/. No build, external fonts, analytics or package installation is required.

## Deployment

Copy the contents of this directory to the repository root. In Settings > Pages, select Deploy from a branch, main, and / (root), then save. Merge the reviewed changes before checking the public URLs. Preserve /labra-site/ in canonical URLs and sitemap.

Expected pages: https://aecttann.github.io/labra-site/uk/ and /en/, with privacy.html and terms.html in each language directory. Verify successful public HTTPS responses before entering a privacy URL in Play Console.

Legal pages describe the Android implementation reviewed on 16 October 2026. Review policy and screenshots again whenever data handling or app features change. Do not add a Play download link until the real listing is live.
